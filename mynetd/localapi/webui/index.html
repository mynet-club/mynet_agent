首次运行向导

登录 → 选节点 → 下载配置。口令只经本机管道交给 mynet auth login --password-stdin，不会进命令行参数； 口令与令牌都不进浏览器，只存在本机 conf/credential.json（0600）。

这一步会：在本机生成节点密钥 → 上传公钥到 back → 写 conf/mynet.conf → 下载配置到 var/bundle.json。 私钥不上传、不出本机。

配置已就位。下一步把隧道拉起来 —— 不启动的话节点只是"配好了"，还没在跑。

隧道要建 tun 设备，需要特权（节点部署下 mynetd 以 root 跑；本机调试请用 sudo 启 mynetd）。 装成开机自启：mynet install --gateways wss://…
