# 本机面板交互与接入（2026-10-09）

概览以实际状态决定下一步：未接入时登录并创建/选择设备；接入未完成时继续接入；降级与失败时查看诊断；已停止时启动连接。状态不可读取时保留上次数据，明确标注“上次状态”和更新时间，禁止将旧快照显示为当前运行状态。

普通接入通过一次 `POST /api/v1/config/connect` 完成。失败步骤和已完成步骤持续显示，避免仅靠短暂通知；会话失效提供重新登录入口。配置修改互斥，状态与只读命令可以并行。服务端返回 `operation_in_progress` 时先刷新状态再重试；浏览器等待超时不意味着后台操作已取消。

身份、密钥、配置生成、驱动启停与系统路由均调用执行器 Ops；浏览器不传私钥，接入返回不含密钥。启动或系统路由失败会尝试停止未完成的连接，清理失败也列入步骤，禁止宣称接入成功。具体接口契约见知识库 `spec/local-api.md`。

视觉采用与 GUI 一致的蓝色、清晰边框和低阴影；跟随系统深色偏好。手机导航可横向滚动，主体不产生水平溢出。键盘焦点明确，危险确认支持取消和 Escape，专家设置支持展开和收起。

验证入口：

- `make check`：Go 全量与结构守护。
- `go test -race ./mynetd/localapi -run 'TestConnect|TestConfigReadMethods'`：配置互斥、只读并行、失败停止、敏感输出脱敏。
- `go test -tags embed ./mynetd/localapi`：发布形态。
- `node scripts/tests/device-flow.mjs`：实际 WebUI 函数的接入、重试、内嵌桥校验。
- `node scripts/tests/webui-tools.mjs`：HTTP 失败、超时清理、忙态、重复点击和临时断连保持身份。

浏览器使用真实 HTML/CSS/JavaScript 与隔离的模拟 API，已验证失败后重试成功、重复点击一次请求、390px 深色布局无水平溢出、Escape 关闭停止确认、服务失联保留身份和上次状态。模拟 API 不构成实机联网验收。浏览器截图接口超时，未形成截图交付件。
