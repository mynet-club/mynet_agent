## 一、设计 Token（全站钉死）

### 1.1 色彩

| Token | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#F7F8FA` | 页面底 |
| `--bg-card` | `#FFFFFF` | 卡片、面板 |
| `--bg-muted` | `#F1F3F5` | 只读块、代码底、禁用区 |
| `--line` | `#E5E7EB` | 边框、分隔线（1px） |
| `--ink-1` | `#111827` | 主文字、标题 |
| `--ink-2` | `#4B5563` | 次要文字 |
| `--ink-3` | `#9CA3AF` | 说明、占位 |
| `--brand` | `#2563EB` | 主操作、选中、链接 |
| `--ok` | `#16A34A` | 正常/在线 |
| `--warn` | `#F59E0B` | 降级/待处理 |
| `--err` | `#DC2626` | 错误/危险 |

深色模式同义替换（`--bg-page:#0F1419` 等），由 Quasar dark 变量统一驱动，**禁止页面各写各的灰**。

### 1.2 字体与字阶

| 用途 | 字号/行高 | 字重 | 颜色 |
|---|---|---|---|
| 页面标题 | 20 / 28 | 650 | ink-1 |
| 卡片标题 | 13 / 18 | 650 | ink-2 |
| 正文 | 14 / 22 | 400 | ink-1 |
| 表格 | 13 / 20 | 400 | ink-1 |
| 说明/副标题 | 12 / 18 | 400 | ink-3 |
| 数值指标 | 22 / 28 | 650 | ink-1 |
| 等宽（IP/ID/原文） | 12 / 18 | 400 | mono |

数字与 ID 一律 `tabular-nums`；**ID 不得当主标题**（用名称，ID 作副行 12px ink-3）。

### 1.3 间距 / 圆角 / 层级

- 基准 4px；常用：8 / 12 / 16 / 24
- 页面左右边距 24px（≥900px）、16px（&lt;900px）
- 卡片内边距 16px；卡间距 16px；区块（卡组之间）24px
- 圆角：卡 12px、输入/按钮 8px、chip 999px
- 阴影：默认无；仅弹层 `0 8px 24px rgba(17,24,39,.12)`
- 控件高度：按钮 36px、输入 36px、图标按钮 32px

## 二、布局系统

### 2.1 壳层

```
┌─ 顶栏 44px：品牌+形态 | 会话面包屑 | 语言 主题 刷新 ─┐
├─ 侧栏 220px（固定，随主题） ┬─ 内容区 max 1280 ────┤
│  导航项 40px 行高          │  页标题 + 页头操作     │
│                            │  状态横幅（可选）      │
│                            │  指标行（等高）        │
│                            │  主卡区                │
└────────────────────────────┴───────────────────────┘
```

### 2.2 每页固定三段

1. **页头行**：标题（20px）+ 右侧**唯一**主操作（至多 1 个 primary + 1 个次操作）
2. **摘要区**（可选）：指标卡 3–4 列等高（≥125px），或状态横幅
3. **内容区**：卡片网格或 Tab 面板

### 2.3 卡片规格

| 类型 | 用途 | 规格 |
|---|---|---|
| **信息卡** | 只读事实 | `dl` 两列（96px + 1fr），12px 标签 / 13px 值；**无输入框** |
| **指标卡** | 一个数 + 一行说明 | 标签 12px、数值 22px、说明 12px；三卡等高 |
| **操作卡** | 表单 + 按钮 | 标题 + 一个主按钮（卡内只一个 primary） |
| **列表卡** | 表格 | 表头 12px ink-2，行 13px，行高 40px |

**禁止**：卡内多 primary、信息卡套输入框、同页卡片高度无故不齐、正文区大面积空白（空态必须给「下一步动作」）。

### 2.4 表格与分页（钉死）

- **日志/事件流：禁止分页**。连续列表 + 顶部行数控件（50/100/200）+ 底部「加载更多」/自动追底。
- 仅「静态清单」（对端表、备份表）允许分页；页大小 15/30/50，底栏**中文化**：
  `每页 15 条 · 1–15 / 80`，图标前后一致，禁用英文 `Records per page`。
- 列宽：名称 ≥120px、IP 等宽 140px、动作列右对齐 88px。
- **空表**：表体一行占位文案（如「暂无对端」），不留纯空白。

## 三、交互规范

| 场景 | 行为 |
|---|---|
| 加载 | 卡内骨架或 spinner，**不整页白** |
| 空态 | 图标 + 一句话 + **一个** CTA（如「运行检查」「去登录」） |
| 错误 | 卡顶红条 + reason_code；可重试给按钮 |
| 保存 | 每卡/每 Tab **一个**保存；页头主操作只服务该页主流程 |
| 危险操作 | 二次确认，文案写清后果 |
| 面板展开 | 默认收起；点「配置」展开；开启开关才允许编辑 |
| 列表编辑 | 左编辑 / 右只读备查，两列等高（`min-height` 拉齐） |
| 表单标签 | 标签在上、输入通栏、帮助文字 12px 在下 |

**按钮层级（配色怎么选，钉死）**

| 层级 | 形态 | 用途 | 例 |
|---|---|---|---|
| **Primary** | `color="primary"` 实心蓝 | 该区唯一主操作 | 保存加速配置 / 登录 / 运行检查 |
| **Secondary** | `outline color="primary"` 蓝描边 | 同区次要操作 | 重置 / 导出 / 刷新 |
| **Ghost** | `flat` 无描边 | 弱动作、链接型 | 查看日志 / 稍后 |
| **Danger** | `color="negative" outline` | 不可逆/停止 | 生成新密钥 / 停止连接 |

- **禁止裸 `outline`**（会得黑/墨描边，与蓝描边混用显脏）——一律 `outline color="primary"` 或 `color="negative" outline`。
- 水平内边距：普通 `0 16px`、dense `0 14px`；高 36px（dense 32px）。全局强制，不逐按钮写。

**纵向节奏（Tab/区块间距，钉死）**

| 场景 | 间距 |
|---|---|
| Tab 条 → 面板内容 | **16px**（面板 `padding: 16px 0 8px`） |
| 面板内操作行 → 正文 | 16px |
| 卡标题 → 卡内容 | 12px |
| 页标题 → 内容 | 16px |
| 空态块上下 | 24px |

## 五、整改方案（分三批，不动手仅计划）

### 批次 1 · 止血（半天）
1. **表格全站中文化**：Quasar 表格分页文案 `paginationLabel` / `rowsPerPageLabel` 统一中文；或直接禁用分页。
2. **日志去分页**：改为 `rowsPerPage=100` + 「加载更多」追加 events。
3. **修名称显示**：首页节点名称用 `identity.node_name`，ID 作副行。
4. **指标卡等高**：缺失路由卡补副行；三卡统一 `min-height:125px`。

### 批次 2 · 布局对齐（一天）
5. 加速页：域名面板两列 `align-stretch` 等高；「刷新云端」进面板标题行；「重置」与「保存加速配置」同侧。
6. 设置页：驱动原文块 `max-height:280px` + 「展开全部」。
7. 诊断页：载入即自动跑 check（或空态 CTA「运行检查」）；「导出」并入「原始状态」。
8. 按钮层级统一：页头 1 primary + ghost；卡内按钮 `dense` 32px。

### 批次 3 · 视觉收敛（一天）
9. Token 落地：全站只引用 `design-tokens`（现散落 var() 各页自写）。
10. 字阶/间距按 §1.3 逐页校对（首页、网络、加速优先）。
11. 空态/错误/加载三态统一组件（`MynetAsyncState` 已有，补空态 CTA 插槽）。
12. 深浅色抽查 + 1280/900/640 三宽度复测。

### 验收标准（整改后）
- [ ] 全站无英文分页/英文表头残留
- [ ] 日志无分页，可连续滚动/加载更多
- [ ] 同一行卡片等高；无 &gt;600px 的原文通天块
- [ ] 每页空态都有 CTA
- [ ] 无 ID 顶替名称
- [ ] 三宽度无横向溢出；深浅色均可读
