# WebUI 信息架构（IA）— 三行壳层

> ⚠️ **双层 Tab 壳层已由 [webui-spa-ux-spec.md](webui-spa-ux-spec.md) 取代**（2026-10-27）。
> SPA 采用侧栏 + 信息/操作分离，不再使用页面 Tab；本文档仅作历史参考。


> 更新：2026-09-27 · 适用：`mynet_agent` 本机 WebUI（`/ui/`）
> 布局契约见 §2；与旧 Dashboard/Config/Monitor 草稿的关系见 §6。

---

## 1. 原则

1. **三行壳层全站固定**：路径导航 → 页面核心卡片 → 页内 Tab。
2. **每页一张主卡片**：放当前页最重要的状态、统计或操作，不堆明细。
3. **明细进 Tab**：同一页面内的切换，不跳页。
4. **默认给人看状态和动作**；JSON / conf 原文一律进「原始数据」并默认折叠。
5. **低频旁路**：配置向导、管理模式/运行设备切换走模态，不占一级导航。

## 2. 壳层：双层 Tab + 主卡片

```text
┌──────────────────────────────────────────────────────────────┐
│ MyNet  ›  当前页  ›  当前功能区        当前网络  切换  刷新    │ ① 顶栏 + 面包屑
├──────────────────────────────────────────────────────────────┤
│  [概览]    [路由]    [诊断与日志]    [网络空间]                │ ② 第一层 Tab：页面
├──────────────────────────────────────────────────────────────┤
│  页面核心卡片：状态 + 关键数 + 主操作                          │ ③ 主卡片
├──────────────────────────────────────────────────────────────┤
│  [功能区 1]    [功能区 2]    [功能区 3]                        │ ④ 第二层 Tab：功能区
├──────────────────────────────────────────────────────────────┤
│  当前功能区内容                                                │
└──────────────────────────────────────────────────────────────┘
```

- **① 顶栏**：面包屑 `MyNet › 页面 › 功能区`；右侧「当前网络」色点+名称、`切换`、`刷新`。
- **② 第一层 Tab（页面）**：概览 / 路由 / 诊断与日志 / 网络空间——**可点切换**，不是纯面包屑。
- **③ 核心卡片**：每页有且只有一张，放在两层 Tab 之间。
- **④ 第二层 Tab（功能区）**：只切换本页内容；hash 为 `#page/tab`（如 `#overview/settings`）。

## 3. 页面地图

```text
MyNet
├── 概览          #overview
│   ├── 节点状态  #overview/nodes
│   └── 系统状态  #overview/system
├── 配置          #config
│   ├── 身份与密钥 #config/keys
│   ├── 运行配置  #config/runtime
│   └── 转发出口  #config/proxy
├── 路由          #routes
│   ├── 路由列表  #routes/list
│   └── 网络拓扑  #routes/topo
├── 诊断与日志    #diag
│   ├── 运行诊断  #diag/run
│   ├── 操作日志  #diag/log
│   └── 原始数据  #diag/raw
└── 网络空间      #space
    ├── 网络空间  #space/embed        （内嵌 /gui/ 控制台）
    └── 连接信息  #space/info
```

命名约定：
- **页面** = 第一层 Tab（概览 / 配置 / 路由 / 诊断与日志 / 网络空间）
- **主卡片** = 每页顶部那一张核心卡片
- **信息区 / 功能区** = 主卡片下方的第二层 Tab

### 3.1 各页核心卡片

| 页 | 核心卡片内容 | 主操作 |
|---|---|---|
| **概览** | 运行态色点 + 一句话；当前网络 / 网络地址 / 在线设备 / 已运行 | 重新连接 · 停止（或 启动 · 配置） |
| **路由** | 总路由 / 正常 / 冲突 / 不可达 | 刷新 · 修复路由 |
| **诊断与日志** | 系统健康检查项（●） | 重新检查 |
| **网络空间** | 连接状态 + 转发方式 | 重新载入 · 在新窗口打开 |

## 4. 数据分层

| 层级 | 内容 | 出现方式 |
|---|---|---|
| **L0 状态** | 运行态、网络名、地址、在线设备 | 核心卡片，常显 |
| **L1 动作** | 启停、修复路由、重新检查 | 跟随核心卡片 |
| **L2 明细** | 节点身份、路由表、诊断项 | Tab 内容 |
| **L3 原始** | JSON、conf、manifest | 「原始数据」默认折叠 |

## 5. 占位约定（后端未接入）

以下字段本轮 **UI 占位**，不编造数值；后端就绪后替换：

| UI 项 | 占位表现 |
|---|---|
| 防火墙状态 | 徽章「未检测」+ 说明 |
| 路由冲突数 | 恒显示 0，并标注占位 |
| 操作日志持久化 | 仅会话内记录，刷新清空 |
| Gateway 连接细节 | 有则显示，无则「—」 |

## 6. 与旧稿的关系

旧 `webui-ia.md`（Dashboard / Config / Monitor + 三层头部）是概念草稿，
**布局契约以本文三行壳层为准**。概念模型（配置运行空间、密钥成对、
运行配置生成、向导步骤）仍然有效，落点调整为：

| 概念 | 新落点 |
|---|---|
| Dashboard 状态 | 概览 · 核心卡片 |
| Config（密钥/插件/运行配置） | 概览 · Tab「网络设置」 |
| Monitor | 路由 + 诊断与日志 |
| 原始数据 | 各页折叠区 + 诊断 · Tab「原始数据」 |
| 向导 / 切换空间 | 顶栏「切换」与低频模态，不进一级导航 |

## 7. 实现对应

| 概念 | 落点 |
|---|---|
| 壳层与四页 | `mynetd/localapi/webui/index.html` |
| 术语 tip + 模式/设备切换 | `mynetd/localapi/webui/webui-context.js` |
| 状态 API | `/api/v1/node-status` · `/api/v1/status` · `/api/v1/config/*` |
| 网络空间 iframe | `/gui/`（经本机 relay） |

安全红线不变：embed WebUI 校验 Origin/Host；私钥默认不展示；动态内容走 `esc()`。
