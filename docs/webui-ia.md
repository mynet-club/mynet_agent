# WebUI 信息架构（IA）— 配置运行空间

> 更新：2026-09-26 · 适用：`mynet_agent` 本机 WebUI（`/ui/`）  
> 术语 SSOT：**配置运行空间**（Workspace），简称「空间」。  
> 前置讨论结论：向导低频；默认给人看状态与动作；JSON/原文进「原始数据」。

---

## 1. 概念模型

### 1.1 配置运行空间（Workspace）

一套可独立运行的配置，包含：

| 要素 | 说明 |
|---|---|
| **来源** | `local`（不连 mynet）或 `online`（mynet 租户下发） |
| **节点** | 节点 ID、overlay、驱动（`gnb` \| `wireguard`） |
| **密钥** | `public` / `private` 成对（节点通信身份） |
| **运行配置** | 驱动原生产物（gnb：node/route/address；wg：wg0.conf）+ keys 投影 |
| **运行态** | 未启动 / 运行中 / 降级 / 异常 |

约束：

- 可存在**多个空间**；**同一时刻只激活一个**。
- 切换 / 新建是**低频**操作，不占主导航主视线。
- 拉取节点**永不含 private**（服务端不存）；必须 **恢复** 或 **生成**。

### 1.2 与旧「zone」的关系

「空间」承接原 zone 的「运行上下文」语义，但包含来源、节点、密钥、运行配置与激活态，不再是单纯分区标签。

## 2. 三层头部（全站固定）

```text
┌────────────────────────────────────────────────────────────────────┐
│ Logo    Dashboard    Config    Monitor              [切换空间] [+]  │
│                                                                    │
│ 空间：local                                                    ●   │
│ 空间：mynet → 租户A → 节点181                              ● 运行中 │
│                                                                    │
│ 节点 181 · 10.182.236.181 · WAN 52.x.x.x · proxy: on               │
└────────────────────────────────────────────────────────────────────┘
```

| 层 | 内容 | 规则 |
|---|---|---|
| **L1 导航** | Logo · Dashboard · Config · Monitor + 右上 **切换空间** · **+** | 无「向导」入口 |
| **L2 空间** | `local` 或 `mynet → 租户名 → 节点名` + 运行态色点 | 激活空间一目了然 |
| **L3 本机身份** | 节点名 \| overlay IP \| WAN IP \| proxy on/off | 只读摘要，不堆配置 |

**[+]** = 新建运行空间（进向导）  
**[切换空间]** = 打开空间列表（Config 的核心区块）

## 3. 页面地图

```text
Dashboard          日常运行（默认首页）
Config             运行空间：列表 / 激活 / 新建 / 密钥 / 运行配置
Monitor            对端、路由、质量、日志
─────────────────
原始数据（旁路）    JSON / conf 原文，默认折叠
配置向导（旁路）    仅 Config → [+] 或「新建空间」进入
```

### 3.1 Dashboard（高频）

| 区块 | 默认给人看 | 不放 |
|---|---|---|
| 状态条 | 「运行中 · 10.182.236.181 · 对端 1/1」 | 密钥、JSON |
| 操作 | 启动 / 停止 / 打开面板 | 新建空间 |
| 摘要 | proxy on/off · 最近告警 | 路由表全文 |
| 「原始数据」折叠 | 有则展开 node-status JSON | 默认展开 |

### 3.2 Config（节点配置）

**Config 配的是「当前空间里的节点」**，不是空间本身。  
空间在 **L1 右上角 [切换空间] / [+]** 选完即定，不在 Config 里堆 CRUD。

| 区块 | 内容 |
|---|---|
| **A. 节点密钥** | public/private：恢复 · 粘贴/导入 · 生成 ·（联网）上传公钥 |
| **B. 插件（节点级）** | 以 proxy 为主：启用/停用、出口 peer、权重、顺序 |
| **C. 运行配置** | 拉取/生成 node·route·address（或 wg）投影；缺则引导 |

**A. 节点密钥（主）**

```text
密钥状态：public 6922e474… · private ✓ · 来源：恢复/生成
[粘贴密钥] [导入文件] [生成新密钥]
（联网）[上传公钥到 back]
```

| 来源 | public | private | 必做 |
|---|---|---|---|
| 联网拉取 | 有 | **必无** | 恢复或生成 → 上传 public |
| 本地新建 | 可无 | 可无 | 生成或粘贴/导入 |
| 备份恢复 | 有 | 有 | 校验成对后落盘 |

- **默认不展示 private**；原始 hex 进「原始数据」。
- 生成 → 上传 public → **服务端通知其他节点更新**。

**B. 插件（节点级）**

```text
proxy 插件                    [启用]
出口：1005… (w=20) 1008… (w=5)
[+ 添加出口]  [排序/权重]
「原始数据」→ proxy.json
```

- 插件配置挂在**当前节点空间**下，切换空间后跟节点走。
- 与 GNB `proxy on` 是两层：插件是开关与选点；驱动投影是 proxy.conf / f 节点。

**C. 运行配置**

```text
运行配置：✓ 已生成（gnb）· revision
[从服务端拉取] [创建本地配置] [从备份恢复]
「原始数据」→ node.conf / route.conf / address.conf
```

**空间卡片若要露出**，仅作**只读摘要 + 激活**，不在此做「配置空间」。

---

## 4. 密钥与插件在 Config 的位置

见 §3.2。**Config 主内容 = 节点密钥 + 节点插件**；运行配置为前置能力区。
空间选择只在 L1：`[切换空间]` / `[+]`。

**判据（钉死）：**

| 来源 | public | private | 必做 |
|---|---|---|---|
| 联网拉取 | 有 | **必无** | 恢复或生成 → 上传 public |
| 本地新建 | 可无 | 可无 | 生成或粘贴/导入 |
| 备份恢复 | 有 | 有 | 校验成对后落盘 |

**UI（默认）：**

```text
密钥状态：public 6922e474… · private ✓ · 来源：恢复/生成
[粘贴密钥] [导入文件] [生成新密钥]
（生成后）[上传公钥到 back]  ← 联网才出现
```

- **默认不展示 private**；原始 hex 进「原始数据」或显式「显示」。
- 生成 → 上传 public → **服务端通知其他节点更新**（与 claim/publish 同链）。

## 5. 运行配置生成（⑤，激活前必做）

| 空间类型 | 恢复备份 | 全新创建 | 产物 |
|---|---|---|---|
| **联网** | 可选 | 密钥就绪后 | **从 back 拉**：node.conf / route.conf / address.conf / ed25519/ / security/ |
| **本地 · gnb** | 直接落盘 | **向导（gnb 表单）** | 本地渲染 node/route/address |
| **本地 · wg** | 直接落盘 | **向导（wg 表单）** | 本地渲染 wg0.conf |

**本地创建字段（驱动分叉，不是一张表）：**

| 字段 | gnb | wireguard |
|---|---|---|
| 节点 ID / overlay | ✓ | ✓（接口地址） |
| listen / MTU | ✓ | ✓ |
| 对端 endpoint | ✓ | ✓ |
| 对端公钥 | GNB ed25519 布局 | X25519 |
| 路由 | route.conf | AllowedIPs |
| 发现 | index / address.conf | — |
| forward / proxy | f 节点、proxy on | 无等价 |

**UI：**

```text
运行配置：✓ 已生成（gnb）· 时间 · 版本/revision
[从服务端拉取] [创建本地配置] [从备份恢复]
「原始数据」→ node.conf / route.conf / address.conf / manifest
```

---

## 6. 向导（低频，完整步骤）

```text
[+] 新建运行空间
  ① 来源     ( ) 本地配置    ( ) 联网配置
  ② 节点     联网：登录 → 租户 → 节点列表
             本地：手工节点身份（ID / overlay / 驱动）
  ③ 密钥     恢复 | 生成 | 粘贴/导入
             联网生成后 → 上传 public
  ④ 运行配置 联网：拉取
             本地：按 gnb|wg 填表创建 / 或从备份恢复
  ⑤ 启动     apply + 起隧道
  ⑥ 保存     存为空间 · 是否立即激活
```

与主界面关系：仅 **Config → +** 或卡片 **[继续配置]** 进入；L1 无向导按钮。

---

## 7. 切换空间（低频）

```text
[切换空间]
  ● mynet → 租户A → 节点181    运行中
  ○ local                      [激活]
  ○ mynet → 租户A → 节点183    [继续配置] 或 [激活]
```

**激活顺序：** 停当前空间 → 读目标空间意图/密钥/运行配置 → apply → 起隧道。  
密钥或运行配置不完整时 **禁止激活**，卡片引导补全。

## 8. Monitor（中频）

| 默认 | 原始数据（折叠） |
|---|---|
| 对端列表：在线、时延、路由是否装上 | gnb.map 摘要 |
| 隧道质量、丢包 | route.conf 原文 |
| 近期告警 | 日志 |

---

## 9. 信息分层总则

| 层级 | 内容 | 出现方式 |
|---|---|---|
| **L0 状态** | 运行态、空间名、overlay、proxy | 头部 + Dashboard，常显 |
| **L1 动作** | 启停、恢复密钥、拉配置、激活 | 跟随缺口按钮 |
| **L2 明细** | 密钥来源、revision、驱动类型 | 详情页正文 |
| **L3 原始** | JSON、conf、manifest、hex | 默认折叠「原始数据」 |

原则：**默认是状态和动作**；技术原文一律旁路展开。

## 10. 导航与路由（建议）

| 路径 | 页 |
|---|---|
| `/ui/` | Dashboard |
| `/ui/config` | **节点配置**：密钥 · 插件 · 运行配置 |
| `/ui/config/new` | 向导（+，仅建空间） |
| `/ui/monitor` | Monitor |

L1：Dashboard · Config · Monitor；空间在右上角 **切换 / +**。  
Config **不是**空间列表页。

## 11. 文案与术语

| 用语 | 含义 | 避免 |
|---|---|---|
| 配置运行空间 | Workspace | zone、配置来源 |
| 激活 / 当前空间 | 正在跑的那套 | 当前配置（过泛） |
| 节点密钥 | public/private 对 | 证书、身份文件 |
| 运行配置 | 驱动产物 + keys 投影 | 配置文件（过泛） |
| 恢复 / 生成 | 密钥两种补全方式 | 重置（易误解为销毁） |

---

## 12. 验收清单（IA 级）

- [ ] 首启无配置 → 引导「本地 | 联网」二选一  
- [ ] 选中节点后必进「密钥」；拉取节点无 private 时只能恢复/生成  
- [ ] 密钥成对后必进「生成运行配置」；联网拉取 / 本地按 gnb|wg 创建  
- [ ] 运行配置齐套后才能启动  
- [ ] L1 无向导；向导仅 [+] / 继续配置  
- [ ] 默认无 JSON 大段原文；原始数据需主动展开  
- [ ] 头部三层齐全；空间可多套、可切换、可再新建
